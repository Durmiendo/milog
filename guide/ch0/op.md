Арифметику выполняет `op`. Формат всегда один:

```
op операция приёмник первый второй
```

Приёмник это переменная, куда ляжет результат. Операндами могут быть числа или переменные.

| Операция | Действие |
| --- | --- |
| `add` | сложение |
| `sub` | вычитание |
| `mul` | умножение |
| `div` | деление |
| `idiv` | целочисленное деление |
| `mod` | остаток от деления |
| `max` | большее из двух |
| `min` | меньшее из двух |

Приёмник может совпадать с операндом. Строка `op add sum sum i` читается как "прибавить `i` к `sum`", это основа любого накопления.

## Задача

Посчитайте `(a + b) * 2` и положите результат в `result`.

Ограничения:

- строки с исходными значениями менять нельзя;
- всего не больше пяти инструкций.

<Proc lesson="ch0-op">
<World>

```code
set a 7 #lock move edit
set b 3 #lock move edit
```

```tests
req var result equals 20 <"result должен быть равен 20">;
req code uses op <"Значение нужно вычислить через op">;
limit instruct 5 <"Не больше пяти инструкций">;
```

</World>
</Proc>

::: details Решение

```
set a 7
set b 3
op add result a b
op mul result result 2
```

:::

Одна инструкция `op` считает ровно одно действие. Длинная формула разбивается на цепочку строк, промежуточные значения хранятся в переменных.
