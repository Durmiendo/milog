Цель главы: понять модель исполнения. Никаких полезных схем здесь ещё нет, есть только процессор и его правила.

## Итог главы

После шести уроков вы сможете:

- читать код процессора построчно и предсказывать результат;
- заводить переменные и копировать значения;
- считать арифметику через `op`;
- объяснить, что такое `@counter` и почему код идёт по кругу;
- ветвить исполнение через `jump`;
- собрать цикл со счётчиком и выходом.

## Правила процессора

| Правило | Что означает |
| --- | --- |
| Одна инструкция за такт | Процессор выполняет строку и переходит к следующей |
| Код идёт по кругу | После последней строки исполнение возвращается на нулевую |
| Переменные общие | Все строки видят один набор переменных |
| Переменная создаётся записью | Первая запись задаёт значение, до неё переменная равна нулю |
