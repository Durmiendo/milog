Процессор это список инструкций. Слева от каждого блока стоит номер строки, он же адрес. Исполнение начинается с нулевой строки и идёт вниз, по одной инструкции за такт.

Инструкция `set` записывает значение в переменную:

```
set имя значение
```

Переменная не объявляется заранее. Пока в неё ничего не записали, она равна нулю.

## Задача

Сделайте так, чтобы переменная `result` стала равна 42.

Порядок работы:

1. Впишите нужное значение в поле блока `set`.
2. Нажмите `run` один раз.
3. Откройте `vars` и убедитесь, что значение изменилось.

<Proc lesson="ch0-run">
<World>

```code
set result 0
```

```tests
req var result equals 42 <"Переменная result должна быть равна 42">;
limit instruct 1 <"Достаточно одной инструкции">;
```

</World>
</Proc>

::: details Решение

```
set result 42
```

:::

Нажмите `run` ещё несколько раз. Счётчик уходит за последнюю строку и возвращается на нулевую, поэтому `set` выполняется снова и снова. Это нормальное поведение: процессор в игре работает постоянно, пока подано питание.
