Вывод текста идёт в два этапа. Сначала процессор набирает строку в собственном буфере, затем отдаёт её блоку целиком.

```
print значение
printflush message1
```

`print` дописывает значение в конец буфера. Вызовов может быть сколько угодно, они склеиваются. `printflush` отправляет накопленное в блок и очищает буфер.

Текст в кавычках это обычный аргумент: `print "Руда: "`. Пробел внутри кавычек сохраняется, о нём нужно помнить, иначе слова слипнутся.

Без `printflush` буфер продолжает расти, а на блоке ничего не меняется.

## Задача

Выведите в `message1` строку `Руда: 7`.

Ограничения:

- строку с исходным значением менять нельзя;
- число берётся из переменной, а не вписывается в текст;
- всего не больше четырёх инструкций.

::: details Решение

```
set ore 7
print "Руда: "
print ore
printflush message1
```

:::

Результат виден по кнопке `mocks`, поле `text` у блока `message1`.

Процессор идёт по кругу, поэтому строка собирается заново на каждом проходе. Это правильное поведение для табло: оно всегда показывает свежее значение.
