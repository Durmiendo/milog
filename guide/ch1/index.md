Цель главы: связать процессор с внешним миром. Здесь появляются блоки, которые можно читать и которыми можно управлять, и первые схемы, которые имеют смысл на карте.

## Итог главы

После шести уроков вы сможете:

- собирать и выводить текст в блок сообщений;
- подставлять значения в шаблон строки;
- хранить данные в ячейке памяти между проходами;
- читать состояние блока датчиком и управлять другим блоком;
- рисовать на дисплее;
- собрать законченный индикатор из памяти, текста и графики.

## Связи

Процессор видит только те блоки, к которым протянута связь. Каждая связь получает имя по типу блока и порядковому номеру: `cell1`, `display1`, `message1`, `switch1`. Это имя и подставляется в инструкции.

В уроках связи уже настроены. Посмотреть их состав, содержимое памяти и картинку на дисплее можно кнопкой `mocks`.

| Инструкция | Назначение |
| --- | --- |
| `print` | добавить значение в текстовый буфер |
| `format` | подставить значение в шаблон `{0}` |
| `printflush` | отправить буфер в блок сообщений |
| `read` | прочитать число из ячейки памяти |
| `write` | записать число в ячейку памяти |
| `sensor` | прочитать свойство блока |
| `control` | задать свойство блока |
| `draw` | добавить команду рисования в буфер |
| `drawflush` | отправить буфер на дисплей |
