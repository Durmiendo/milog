Цепочка из четырёх `print` работает, но плохо читается: текст разорван на куски, а порядок вывода задан порядком строк.

`format` решает это. Сначала в буфер кладётся шаблон с метками `{0}`, `{1}`, `{2}`, затем каждый вызов `format` заменяет метку с наименьшим номером на своё значение.

```
print "Медь: {0} / {1}"
format copper
format cap
```

Правила простые:

- метка нумеруется от нуля и пишется без пробелов;
- порядок вызовов `format` определяет, какая метка заменится первой;
- если меток меньше, чем вызовов, лишние значения теряются.

## Задача

Выведите в `message1` строку `Медь: 120 / 300`.

Ограничения:

- исходные строки менять нельзя;
- значения подставляются через `format`, а не склеиваются `print`;
- всего не больше шести инструкций.

::: details Решение

```
set copper 120
set cap 300
print "Медь: {0} / {1}"
format copper
format cap
printflush message1
```

:::

Шаблон удобен тем, что вёрстка табло правится в одной строке. Чтобы поменять разделитель или добавить единицы измерения, трогать логику не нужно.
